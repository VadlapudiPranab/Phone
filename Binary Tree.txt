Heap
=======
It is complete BT with below properties
MAX Heap
----------------------
1.Any node in heap data structure is always > that its child node.
2.Root node is the largest among all nodes.
MIN Heap
-----------------------
1.Any Node in heap data structure is always < that its child node.
2.Root node is the smallest among all nodes.
Heap structure is for only the higher order data structure like Tree.
